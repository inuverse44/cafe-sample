# 制作計画書：星と過ごす珈琲夜（架空のカフェのホームページ）

Inuverse のポートフォリオの見本サイトとして、架空のカフェのホームページを作る。
**実在のお店ではない**ことを、全ページで明示する。

## 1. 目的

| ID | 目的 |
| --- | --- |
| G-01 | 見た人が「お店のサイトをこう作れる」と具体的に想像できる見本にする |
| G-02 | 見た目だけでなく、速さ・アクセシビリティ・更新のしやすさまで含めて見せる |

## 2. お店の設定（架空）

| 項目 | 内容 |
| --- | --- |
| 名前 | 星と過ごす珈琲夜（ほしとすごす こーひーや） |
| コンセプト | 森のそばにある、本と珈琲の小さなカフェ。木のぬくもりと本に囲まれて、夜は星を眺めながら過ごせる |
| 営業 | 夕方から夜にかけての営業（例：15:00〜23:00） |
| 場所 | 架空の地名だけを書き、実在の住所・地図は載せない |

## 3. ページ構成

| ID | ページ | 内容 |
| --- | --- | --- |
| P-01 | トップ | 写真を大きく、コンセプトを一言で。営業時間、メニューとお知らせへの導線 |
| P-02 | メニュー | 珈琲、お茶、焼き菓子、夜の軽食。写真つき |
| P-03 | お店について | 本棚、木の店内、窓から見える森、星を眺めるテラス |
| P-04 | アクセス・営業時間 | 架空の所在地、営業時間、定休日 |
| P-05 | お知らせ | 星空観察会、新しい本の入荷など（Markdown で追加できる） |

## 4. デザインの方針

| 項目 | 方針 |
| --- | --- |
| 雰囲気 | 木・本・自然・夜空。落ち着いていて、あたたかい |
| 色 | 昼（ライト）は白い背景に夜空の紺の文字とリンク。夜（ダーク）は黒に近い紺の背景に、星の金のリンク。ヒーローとフッターは夜空の紺。当初は紙のクリームと木の茶にしたが、茶色すぎるとの意見で変更した |
| 文字 | 見出しは明朝体で、本の雰囲気にする。本文は読みやすいゴシック体。どちらも OS の標準フォントを使い、Web フォントは読み込まない（日本語の Web フォントは CSS が大きく、表示が遅くなるため） |
| 写真 | Unsplash License の写真 4 枚（星空、窓辺の本、珈琲と焼き菓子、草原の先の森）。各ページでライセンスと撮影者を確認し、`CREDITS.md` に記録した。人物や、ほかの作品（本・レコードのジャケットなど）がはっきり写る写真は使わない |

## 5. 技術と品質

以前に作ったホームページの仕組みを使い回す。

| 項目 | 内容 |
| --- | --- |
| 技術 | Astro（静的出力）、GitHub Pages（`https://inuverse44.github.io/cafe-sample/`） |
| 更新のしやすさ | メニューとお知らせは Markdown や YAML のファイルを書き換えるだけで更新できる |
| 品質の基準 | Lighthouse の性能・アクセシビリティ・ベストプラクティスが 90 点以上、axe で重大な違反 0 件、CSP、幅 360px で横スクロールなし |
| 検索エンジン | 架空のお店なので、全ページを `noindex` にする（実在のお店と誤解されないように）。そのため Lighthouse の SEO は基準の対象外とする |
| 検査 | CI で、ビルド・総合テスト・Lighthouse・画像のメタデータを検査する |
